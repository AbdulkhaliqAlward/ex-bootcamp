# C Programming Track - Cybersecurity and Networks Bootcamp

This branch (`c_lang-bootcamp`) contains all labs, assignments, and small security tools developed during the first phase of the bootcamp.


---

## Setup and Compiling

Everything is built using GCC.


### Compiling Any File

To compile a source file, run:

```bash
# Windows
gcc filename.c -o filename.exe


```

Always test the compiled program locally and check for compiler warnings (`-Wall`) before committing.
